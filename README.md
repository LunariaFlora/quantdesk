# 观澜 · 量化回测工作台

在本机导入日线行情，运行双均线趋势策略，查看资产曲线、买入持有对照和逐笔交易。

## 运行

Python 3.10+，不需要安装第三方包。首次运行：

```powershell
python download_data.py
python server.py
```

打开 http://127.0.0.1:8765 。以后只需运行 `python server.py`，或右键运行 `启动.ps1`。
若端口被占用，运行 `python server.py --port 8766` 并打开对应地址。Ctrl+C 停止服务。
样本下载失败仍可启动，页面选择“导入 CSV 文件”。服务仅监听 127.0.0.1，不用于公网部署。

## 使用

1. 选择样本或 CSV，设置日期范围。
2. 设置短/长均线、初始资金、单边手续费和滑点，点击“运行回测”。
3. 移动鼠标查看图表数值；查看交易明细中的信号日期与成交日期。
4. 导出 JSON 完整报告（参数、曲线、交易、数据摘要）或交易 CSV。

CSV 必须包含 `date,open,high,low,close,volume`，也接受 Plotly 样本的 `AAPL.Open` 等列名。
日期格式 YYYY-MM-DD，自动按日期升序，重复日期报错；价格必须为正有限值、成交量非负。
最多 20,000 行，上传最大 3 MB。导入文件只存在当前页面内存和本次请求中，不写入磁盘。
价格必须使用一致口径。跨拆股、除权数据需要用户先整理，本程序不会自动复权。
为避免数值溢出，价格限定在 0.00000001–1,000,000,000,000，成交量不超过 10^18。

## 计算约定

- 收盘时短均线 > 长均线，下一交易日开盘尝试买入；否则卖出已有持仓。相等视为空仓。
- 初次预热完成且已处于多头趋势时，也会买入；不是仅捕捉两线交叉瞬间。
- 仅做多，无杠杆，整数股，资金尽量全额投入。零成交量日不成交。
- 预热使用所选区间的前 slow 根日线，基准也从预热后的第一天开盘开始买入；若无成交量则等待。
- 基准与策略均计相同单边比例佣金和滑点；滑点计入价格，不重复加入手续费统计。
- 回撤相对包括初始本金在内的历史资产峰值计算；显示负值。
- 期末不强制平仓，现金 + 持仓 × 收盘价作为资产；因此未扣假设卖出的费用。
- 未模拟分红、拆股、印花税、最低佣金、涨跌停、成交容量等。不是 A 股完整规则引擎。
- 更改长均线或日期会改变实际交易起点，跨参数比较时必须考虑这一点。

## 数据与复现

数据来自 [Plotly 公开 AAPL 示例](https://github.com/plotly/datasets/blob/master/finance-charts-apple.csv)，
2015-02-17 至 2017-02-16，共 506 根日线。使用原始 OHLC，不使用 Adjusted 列，不含分红总回报。
下载脚本记录原始 SHA-256、下载时间、来源。报告中的 data_sha256 对传入的 UTF-8 CSV 文本计算，换行规范可能与原始文件哈希不同。
数据文件、缓存和导出文件被 Git 忽略。若上游改变，可用本地 metadata.json 的原始哈希确认。

默认 10/30、100000 初始资金、5 bps 手续费、5 bps 滑点：
策略收益约 0.2119%，基准约 7.2340%，策略最大回撤约 -23.8052%，21 笔成交。
这些数值用于复核固定样本和计算约定，不表示策略对未来有效。
