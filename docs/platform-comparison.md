# 成熟平台对照与迭代记录

核验日期：2026-10-05。对照依据为官方项目资料和本机运行证据。未安装并逐个操作所有平台；除 Backtrader 的独立引擎对照外，不是同硬件、同数据的竞速或全面认证。

## 参考对象与选择理由

- [VeighNa 官方 README](https://github.com/vnpy/vnpy/blob/master/README.md)：提供图形回测/优化、历史数据管理、CSV 进出、图表、订单持仓管理和模块化应用。借鉴的是数据管理→策略→研究→记录的桌面流程。其交易网关、实时风控、多合约组合等能力仍超出本版。
- [Backtrader 订单执行](https://www.backtrader.com/docu/order-creation-execution/order-creation-execution/)：明确策略生成订单与后续 bar 成交的区别，有多种订单类型。用独立 broker 和 SMA 实现核对本版的真实样本；本版只提供开盘市价与日线保护规则，没有其完整限价、括号单等体系。
- [LEAN 官方仓库](https://github.com/QuantConnect/Lean)：事件驱动、模型可插拔，并支持多市场回测与实盘。参考其事件与模型边界，本版把策略、指标、执行、数据和服务分离；没有实现相同资产类别和经纪商模型覆盖。
- [vectorbt 官方说明](https://vectorbt.dev/)：数组计算和编译加速适合大批参数研究，支持交互分析。借鉴统一配置、参数网格和结果比较；本版采用逐日事件账本，没有实测 vectorbt，因此不作速度等价声明。

## 七个维度

| 维度 | 本版行为与证据 | 与成熟平台的主要差距 |
|---|---|---|
| 功能 | 真实行情、显式清洗、SQLite、8 类策略、指标、回测、订单/成交/账户、评估、风控、调参、导出 | 单标的日线仅做多；没有实时网关、多资产共享资金和因子研究库 |
| 流程 | 数据→编辑/保存策略→配置→后台回测→结果自动保存→参数/策略比较→导出/重新导入 | 缺少自动滚动样本外研究、数据增量维护和任务调度 |
| 易用性 | 原生窗口无端口；持久记录；失败弹窗与日志；任务进度/取消；实验列排序 | 策略 JSON 编辑器需要字段知识，尚无可视化条件构建器；未进行长期用户可用性研究 |
| 可视化 | OHLC K线、6 类指标、资产/基准、回撤、成交标记、悬停、联动缩放和实验叠加 | 没有成交量副图、年度/月度收益热图、参数热图和图表图片导出按钮 |
| 可靠性 | 手算、无前视、止损跳空/双触发、容量拒绝、账户恒等式、指标分母边界、Backtrader 对照、报告结构检查 | 保护单依赖日线路径假设；未建企业行动、交易所规则、部分成交和 Tick 回放模型 |
| 性能 | 实测 100 组固定样本调参 3.246s；108 个实验摘要读取 0.129s；列表不解码完整日线 | 串行研究；大网格每组保存完整结果会增长磁盘占用；250k 行为导入上限，未经所有图形规模压力认证 |
| 架构 | Qt UI→Service→独立策略/指标/执行→数据适配器与 SQLite；后台任务；源码/EXE 同逻辑 | 无策略插件 API、数据库迁移工具、多用户并发和自动更新/安装器 |

## 已实际实施的迭代

1. 网页服务改为原生 Qt；正式启动不调用 server.py。本地端口只保留历史开发预览。
2. 数据来源、清洗规则、日期与哈希随实验保存；拒绝不同数据/区间直接叠加，避免误导比较。
3. 调参/多策略比较统一开始日期，使用更早行情预热；预热不足不偷偷推迟交易起点。
4. 补齐订单状态、现金/持仓/市值、已实现/未实现盈亏、平仓统计、容量拒绝和保护执行假设。
5. 下载和研究迁入后台；支持取消和诊断。已返回但取消的数据不进入数据集。
6. 实验列表只读取 JSON 摘要，点开才载入全曲线；支持数值列排序。避免保存实验增多后反复解码整库曲线。
7. 图表十字线不参与范围计算，修正行情被 1970 年坐标压缩的问题；完整指标改为纵向表格。
8. 导入报告检查字段、非有限值、日期顺序、账本和摘要一致性。外部报告明确标记未经原始来源认证。
9. 修复载入配置后保存策略可能覆盖另一条已选策略的标识状态。
10. EXE 启动实测发现 Conda ICU DLL 错配，写入可复现打包 spec，使用 Windows ICU 解析 Qt 依赖。

这些是已经落地的改进，不是待办清单。当前定位是可独立使用的历史量化研究桌面工作台；上述缺少的实时和交易所能力不应被包装成已经具备。

## 运行证据

- tests/test_oracle.py：506 根真实 AAPL 日线，在 SMA 10/30、80% 仓位、5 bps 佣金、无滑点配置下，独立 Backtrader 与本版每笔日期/数量/价格/手续费、476 条每日现金/持仓/资产一致到测试容差。Backtrader 的 cheat-on-open 仅用于本次参考引擎在已知次日开盘按同口径定量；指标仍读取前日值。
- outputs/live-audit.json：Yahoo 在线成功，1508 根 AAPL 日线，2020-01-02 至 2025-12-31；8 策略统一交易起点 2020-02-24，约 0.528s，11,784 条账户记录通过恒等式检查。参数性能使用另一个 506 行固定真实样本。
- outputs/packaged-final/acceptance.json：最终 EXE 中运行 8 策略、9 组参数研究、日期查询、恢复和 6 个导出文件；desktop.png 与 comparison.png 为实际窗口截图，进程退出码 0。
- tests/test_desktop.py：原生后台完成回调在 UI 线程；绑定 socket 时强制抛错，桌面流程仍通过；策略更新/另存、配置恢复、报告导入/拒绝异常报告和载入结果通过。
- outputs/packaged-sockets.json：外部采样最终 EXE 的 PID 35776，7 次仍存活采样监听端口数均为 0；随后正常退出。早期启动失败采样不作成功证据。

本机数据下载会受第三方可用性影响。Yahoo 与公开固定样本已成功；Stooq 在本次环境返回非行情内容而失败，错误得到保留。未声称所有供应商此刻均可用。
